# /analyze

Arguments: `$ARGUMENTS`.

1. If `analysis/plan.md` is missing or does not cover this analysis, have the **methodologist** draft or extend it and confirm with the researcher.
2. **analyst** runs it locally (core-methodology plus survey-data-analysis and/or pls-sem skills). Asks before exclusions, transformations or package installs.
3. If a SmartPLS or SPSS output is provided, the analyst cross-checks it and reports differences.
4. Deliver the Quarto report path, the key results in plain language with their source files, and anything that conflicts with the hypotheses or with lessons.md (e.g., CMB, HTMT).
5. Update status and the project log.
