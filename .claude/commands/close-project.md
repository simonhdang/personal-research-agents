# /close-project

Project: `$ARGUMENTS` (ask if missing; list active projects).

1. Determine the mode: **full** (Accepted or Archived) or **light** (Rejected and will be resubmitted: lessons only, project stays open).
2. Delegate to the **archivist** (update-routing skill > Close-project harvest); the librarian helps with construct notes from citable records.
3. Show `projects/<p>/harvest-report.md` as a checklist. Wait for the researcher to tick items.
4. File only the ticked items. Items for `soul.md` or `vault/owner/` become entries in `vault/suggestions.md`.
5. Optional extras if the researcher wants them: a LinkedIn post or plain-language summary draft; a short teaching case.
6. Full mode: move the project to `projects/_archive/<p>/` (mv), set Stage in Notion, close open Tasks, record the publication.
7. Log and summarize.
