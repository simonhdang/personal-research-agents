# Past manuscripts

One subfolder per manuscript (any name) containing everything for it: all versions, decision letters, reviewer reports, response letters, editor emails.

/update will detect journal, round, type and reviewer number; file renamed copies (e.g. `2025-03_JRCS_R2_reviewer-2.pdf`) under `projects/_archive/<manuscript>/submissions/round-N/`; code every reviewer comment into `vault/reviews/ledger.csv`; and update `vault/reviews/lessons.md`.

Only add reviews of your own manuscripts, never reports you wrote or handled for other authors.
